Comparison caveats

Plain text is a non-animated lower-bound reference. NumberFlow uses full directional digit wheels and accumulated effects; Rolling Number uses bounded travel and replacement spring motion. Initial spin/layout easing is matched to the sampled zero-velocity spring where possible; interruption velocity, travel, fades, and layout behavior can differ.

Both animated renderers receive the same requested duration. Offscreen pausing is disabled for Rolling Number; NumberFlow does not test viewport intersection. This workload keeps the document visible and measures all mounted counters, including those below the viewport at larger counts.

rAF intervals are main-thread callback intervals, not compositor-frame measurements. Mounting, update submission, settlement, and element counts are separate metrics. Shadow-root descendants are included in element counts; text nodes and CSS pseudo-elements are not.
